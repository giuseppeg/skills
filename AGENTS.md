# skills — working notes

A repo of agent skills. Each one is a folder under `skills/`, which is all an
install copies, so it holds only what runs. A skill that is built from source
has it in `src/<skill>/`, with its tests and its own `AGENTS.md`. Read that
file before you work on the skill. Nothing in a skill folder may point at
`src/`.

- yourturn: `skills/yourturn/`, source and notes in `src/yourturn/`, design
  and notes in `src/yourturn/docs/`.
